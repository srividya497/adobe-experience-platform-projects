# Adobe Experience Platform & Journey Optimizer Projects

Welcome! This repository is my hands-on portfolio and learning log as I build
skills in **Adobe Experience Platform (AEP)** and **Adobe Journey Optimizer (AJO)**.

## 👋 About Me
I'm Srividya Chekuri, learning to design data-driven customer experiences using
Adobe's marketing technology stack. This repo grows as I complete projects,
experiments, and real use cases.

## 🎯 What This Repo Covers
- **Adobe Experience Platform (AEP)** — data schemas, ingestion, profiles, segments, and Query Service.
- **Adobe Journey Optimizer (AJO)** — customer journeys, campaigns, and personalized messaging.

## 📁 Repository Structure
| Folder | What's inside |
|--------|---------------|
| `xdm-schemas/` | XDM schemas and field groups that define my data models |
| `query-service/` | SQL queries for Query Service and Data Distiller |
| `journeys/` | Documentation of journeys built in AJO |
| `api-scripts/` | Python / JavaScript scripts that call the AEP APIs |

## 🚀 Goals
- Build a strong understanding of AEP's data foundation
- Design and document real-world customer journeys
- Automate tasks using the AEP APIs
